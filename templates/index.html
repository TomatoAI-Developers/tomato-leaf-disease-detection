✦ Capabilities

What It Can Do

🧠

Eight-Model Evaluation

Seven classical machine-learning classifiers are evaluated alongside a MobileNetV2 deep-learning verifier, allowing a transparent comparison of different classification approaches.

🔬

Feature-Based ML Pipeline

MobileNetV2 extracts 1,280-dimensional image features. The classical models use PCA-reduced features for classification, with predictions and evaluation metrics reported separately.

📊

Prediction Confidence

View the selected model’s top predictions and confidence estimates. Confidence for an individual image is different from a model’s overall test accuracy.

⚡

Evaluation Dashboard

Compare accuracy, macro precision, macro recall, macro F1-score, class-wise results, confusion matrices and measured inference time.

💊

Farmer Assistance

Get practical disease-specific care guidance and recommendations. The output is an AI-assisted screening result, not a substitute for an agricultural expert.

📄

Downloadable Reports

Export a diagnosis report with the uploaded image result, model output, confidence, recommendations and relevant evaluation context.

✦ Process

How It Works

1

Upload a Leaf Photo

Take a clear photo of your tomato leaf and upload it directly in the browser. Supports JPG, PNG and JPEG formats. The system immediately checks image quality before proceeding.

2

AI Runs Tri-Stage Detection

The trained verifier distinguishes non-tomato images from tomato leaf categories, including healthy leaves and disease classes. The prediction pipeline then presents the model outputs and evaluation context.

3

Get Instant Diagnosis

Receive a full report: disease name, confidence score, severity level, progression outlook, and a three-tier treatment plan. Download it as a PDF to share with agronomists.

✦ Model laboratory

Inside the 8-Model System

One MobileNetV2 feature extractor and seven classical classifiers are part of the current implementation. Each model is evaluated individually; their outputs are not presented as an ensemble.

🧠

MobileNetV2

Deep-learning verifier trained for 11 output classes. Current test accuracy: 84.16%; macro F1: 82.29%.

🌲

Random Forest

Ensemble of decision trees operating on PCA-reduced MobileNetV2 image features.

📍

K-Nearest Neighbors

Classifies feature vectors using their nearest training examples.

〰️

Support Vector Machine

Calibrated linear SVM classifier for multi-class feature classification.

📈

Logistic Regression

Linear probabilistic classifier applied to PCA-transformed image features.

🌳

Decision Tree

Tree-based classifier that learns decision rules from extracted image features.

🌿

Extra Trees

Extremely randomized tree ensemble for feature-based classification.

⚡

Gradient Boosting

HistGradientBoostingClassifier, trained on the PCA-reduced feature representation.

8 Implemented ML & DL Models

The current pipeline uses MobileNetV2 for feature extraction and verification, with seven separately trained classical classifiers. This is a model comparison system, not an ensemble vote.

ModelRole in the project
MobileNetV2Deep-learning verifier and 1,280-dimensional feature extractor.
SVMCalibrated linear support vector classifier.
Logistic RegressionLinear probabilistic classifier.
Random ForestEnsemble of decision trees.
KNNNearest-neighbor classifier.
Decision TreeSingle tree-based classifier.
Extra TreesExtremely randomized tree ensemble.
HistGradientBoostingHistogram-based gradient boosting classifier.

ResNet50 is not included in this count because a trained and evaluated ResNet50 model has not yet been confirmed. Accuracy, per-image confidence and inference time are different measurements.
